# 선행연구 구성 분석

인문학 논문은 문헌연구 장의 하위 절이 곧 토픽이라 절마다 인용 논문을 세면 된다. 과학 논문(IMRaD)은 선행연구 절이 따로 없다. 선행연구는 서론에 짧게 녹아 있고, 결과·논의에서 다시 많이 인용된다. 유기화학 6편에서는 참고문헌의 약 절반만 서론에서 인용됐다. 그래서 과학 논문은 두 곳을 본다.

- **서론**: 인용 문장을 선행연구 토픽으로 묶는다 → 토픽 수, 토픽당 고유 문헌 수, 토픽 조직, 인용 문장의 주요 동사, 인용 밀도, 통합 인용 비율
- **결과·논의**: 인용 문장마다 선행연구를 어디에 쓰는지 판정한다 → 기능 분포, 인용 밀도, 서론에 없던 새 문헌 수, 인용 문장의 동사

## 절차

`SKILL_DIR` = 이 파일이 있는 폴더, `WORK` = 결과 폴더(예: `litreview_analysis/`). Python 환경은 spacy(en_core_web_sm)·openpyxl·pymupdf가 필요하다. `hedge-verb-sections` 스킬과 같은 `.venv`를 쓰면 된다.

### 1. PDF → 섹션별 문단 + 인용 표지

```bash
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/extract_citations.py WORK/pdf WORK/corpus
```

- 논문마다 참고문헌 수와 섹션별 단어·인용 표지 수를 출력한다. **헤딩 인식, 참고문헌 수(refs None이면 실패), 서론 인용 표지 수를 확인한다.**
- 번호식 위첨자 인용은 `⟦c:1−4⟧`로 남는다. 다음 위첨자는 인용으로 보지 않는다.
  - 단위 지수(cm^-1), 동위원소 접두(^13C), 숫자 뒤 지수(10^5)
  - 참고문헌 최대 번호보다 큰 수
- span이 나뉜 위첨자(`1`,`−`,`4`)는 합친다. 줄마다 끊긴 2010년 서식 문단도 이어 붙인다.
- ACS 서식 기준이다. 다른 저널은 `HEAD`·`RUNNING` 패턴과 참고문헌 번호 형식(`find_nref`)을 맞춘다.

### 2. 문장 분할·인용 문장 추출·자동 판정

```bash
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/litreview.py build WORK/corpus "WORK/선행연구구성_N<편수>.xlsx"
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/litreview.py dump "WORK/선행연구구성_N<편수>.xlsx" WORK/corpus WORK/candidates.txt
```

- **서론**: 인용 문장마다 펼친 문헌 번호, 통합 인용 여부, 동사를 뽑는다. 자동 토픽은 문단(¶n)이다.
- **결과·논의**: 인용 문장 + 앞·뒤 문장을 뽑고, 단서 표현으로 기능을 자동 판정한다.
- 인용 표지는 문장 끝 마침표 뒤 위첨자까지 그 문장에 붙인다.

### 3. Claude 검토 — 후보를 모두 읽는다

`WORK/candidates.txt`를 읽고 **`references/criteria.md`를 따라** `WORK/review_claude.json`을 쓴다.

```json
{
 "intro": {"1": ["QM의 성질과 반응성", "메모"], "56": ["(제외) 본 연구 서술 속 인용", "M3 문단"]},
 "topic_org": {"P01": {"QM의 성질과 반응성": "주제 통합"}},
 "rd": {"1": ["방법·자료 출처", "known procedure"]}
}
```

- **서론 토픽**은 논문별 문단 전체를 읽고 정한다. 토픽은 "어떤 선행연구 흐름을 소개하는가" 단위다.
  - 한 문단에 토픽이 둘이면 나눈다.
  - 두 문단이 같은 흐름이면 같은 이름을 준다.
  - 본 연구를 소개하는 문단(M3) 속 인용은 `(제외)`로 시작하는 이름을 줘서 토픽에서 뺀다.
- **토픽 조직**은 토픽마다 주제 통합 / 논문별 나열 / 혼합 중 하나다.
- **결과·논의 기능**은 앞·뒤 문장을 보고 다섯 가지 중 하나로 고른다.

그런 다음 검토 판정을 붙여 다시 빌드한다:

```bash
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/litreview.py build WORK/corpus "WORK/선행연구구성_N<편수>.xlsx" WORK/review_claude.json
```

### 4. 연구자 최종 판정과 재계산

판정은 연구자 > Claude > 자동 순으로 적용된다. Claude의 판정을 연구자 열에 쓰지 않는다.

- 서론_인용문장 N열 '연구자 토픽'
- 서론_토픽 G열 '연구자 조직 유형'
- 결과논의_인용문장 O열 '연구자 기능'

연구자가 이 열들을 채운 뒤 아래를 실행하면 다시 계산된다.

```bash
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/litreview.py stats "WORK/선행연구구성_N<편수>.xlsx"
```

### 5. (선택) 진단 아티팩트용 기준선

```bash
.venv/Scripts/python -I -X utf8 SKILL_DIR/scripts/litreview.py baseline "WORK/선행연구구성_N<편수>.xlsx" <baseline_lit.json>
```

토픽 수, 토픽당 문헌, 밀도, 기능 비율 등 지표별 논문 값과 논문별 토픽 목록, 인용 문장 동사 상위 40개를 담는다.

## 엑셀 구성

| 시트 | 내용 |
|---|---|
| 서론_인용문장 | 문단, 인용 표지, 펼친 문헌, 통합 인용, 문장, 동사, 자동/Claude/연구자 토픽 |
| 서론_토픽 | 논문별 토픽, 문헌 수, 인용 문장 수, 문헌 번호, 조직 유형 |
| 결과논의_인용문장 | 앞·뒤 문장, 문헌, 자동 기능·근거, Claude/연구자 기능 |
| 섹션크기 | 섹션별 단어·문단·인용 문단·인용 표지·고유 문헌 수 |
| 논문별 요약 | 서론·결과·논의 지표, 기능 비율, 참고문헌의 섹션별 인용 비율 |
| 분야 요약 | 지표별 평균·표준편차·중앙값·최소·최대·출현 논문 수 |
| 인용 문장 동사 | 서론/결과·논의 인용 문장의 동사(출현 논문 수 순) |
| 결과논의 기능 | 기능별 문장 수와 논문별 분포 |

## 보고할 때

- 서론: 토픽 수와 토픽당 문헌 수의 평균(범위)을 말한다. 토픽 이름 예시를 든다. 주제 통합형이 기본인지, 나열형이 어디에 나오는지 말한다.
- 결과·논의: 기능 분포를 말한다. 논문 성격에 따라 크게 갈린다(합성 논문은 방법·자료 출처, 분광·메커니즘 논문은 해석 근거). 결과·논의에서 새로 인용하는 문헌이 몇 편인지 말한다.
- 참고문헌 중 서론에서 인용된 비율을 말한다. 이 비율이 낮으면 선행연구가 결과·논의에 많이 분산된 논문이다.
- 지표마다 편차가 큰 것(기능 비율, 통합 인용)은 표본 6편의 주제 차이 때문일 수 있다고 밝힌다.

## 인문학 문헌연구(참고)

문헌연구 장이 있는 문서는 하위 절이 토픽이다. 절마다 인용된 고유 문헌을 센다(저자-연도 표기). 주제 통합 / 논문별 나열 판단 기준은 과학 논문과 같다. 예를 들어 하위 절 제목이 "3.2.1 Ko (2009)"처럼 논문 한 편이면 논문별 나열형이다. 현재 스크립트는 번호식 인용 PDF만 자동 처리한다. 저자-연도 문서는 이 기준으로 Claude가 직접 세어 같은 지표를 낸다.
