# 마크다운 기반 4개 분야 기준선

입력은 CM·IC·JOC·JPC_C 폴더의 기존 마크다운 100편입니다. PDF를 다시 추출하지 않았습니다.

**규칙 기반 예비 기준선입니다.** 마크다운에서 표 안에 들어간 본문·열 순서 혼합·문장 잘림이 남아 있어 연구용 확정 기준선으로 사용하기 전 원문 검토가 필요합니다. PDF 인용 회수율·레이아웃 검사는 적용하지 않았습니다.

- 환경: Python 3.12.10, spaCy 3.8.11, en_core_web_sm 3.8.0
- 엔진: hedge-baseline-0.4.4. 문장 분리·비문장 제외·표현 판정은 스킬 코드 사용.
- 집계: 알파벳 토큰 분모, 1,000단어당 중간값과 최소–최대, 섹션별 n. 평균·표준편차를 쓰지 않습니다.
- 25편 전체 검토를 위해 집계 CLI의 입력 편수 검사만 --max-papers 25로 확장했습니다. 집계·판정 규칙은 유지했습니다.
- 누락 섹션은 0건으로 채우지 않았습니다. 각 분야의 markdown_gate.json에 포함/제외 사유를 기록했습니다.
- 공통 동사·헷지·강조·보고동사만 이 스킬의 기준선이며 선행연구 토픽 기준선은 포함하지 않습니다.

## 파일 구성

분야별 폴더의 `2_baseline/`에 보고서, baseline.csv, per_paper.csv, common_verbs.csv, evidence.csv, checks.json이 있습니다. `baseline.json`은 앱에 등록한 JSON과 동일합니다. `1_markdown_input/`은 스킬에 전달한 표준 문장 TXT·구조 TSV입니다.

JPC_C 일부 논문은 결과(RES)와 논의(DIS)가 분리되어 있어 별도 행으로 집계됩니다. RD 행은 해당 통합 섹션이 있는 논문만 포함하므로 분야 전체 편수와 n이 다를 수 있습니다.

마크다운 구조가 불명확한 제외 논문을 PDF로 보완하거나 임의로 본문을 추정해 포함하지 않았습니다.
