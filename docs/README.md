# 프로젝트 문서

이 프로젝트는 영어 연구논문의 섹션별 동사·헷지·선행연구 구성을 분석하고, 같은 분야의 출판 논문에서 만든 기준과 비교하는 웹앱입니다. 결과는 규칙 기반 예비 분석이며 논문 품질이나 게재 가능성을 점수화하지 않습니다.

문서 기준일: 2026-10-31. 실제 구현과 저장소에 포함된 기준선 파일을 기준으로 작성했습니다. 배포 서버의 적용 버전은 관리자의 작업에 따라 바뀔 수 있습니다.

앱 상단 **문서** 메뉴 또는 `/guide`에서 이 문서들을 읽을 수 있습니다. 왼쪽 문서 목록·문서 내 목차, 이전/다음 이동, 원본 마크다운 다운로드를 제공합니다. 문서의 저장소 자료 링크는 GitHub로 연결됩니다. `/docs`는 개발자용 API 문서입니다.

## 먼저 알아둘 사항

- 기본 비교 기준은 네 분야의 **마크다운 기반 Stage 1 기준선**입니다. 100편을 입력해 82편을 포함했고 18편을 제외했습니다.
- Stage 1은 **1,000단어당 중간값·최소–최대**를 사용합니다. 기존 GNU 방식의 **10,000단어당 평균·범위**와 섞어 비교하면 안 됩니다.
- 현재 네 분야 기준에는 선행연구 토픽·인용 기능의 분야 기준값이 없습니다. 선행연구 화면은 원고 자체를 분석합니다.
- 관리자 재계산은 검토 대기 버전을 만듭니다. **적용**을 따로 해야 현재 기준이 바뀝니다.
- 서버 실행 데이터는 프로젝트 루트의 `data/`에 저장되며 Git에 포함되지 않습니다. 현재 Render 무료 환경에서는 재배포·재시작 시 소실됩니다.
- 관리자 이름은 이력에 기록하는 이름입니다. 개인별 계정·권한 관리 기능은 없습니다.
