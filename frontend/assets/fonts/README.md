# Local fonts

- SUIT Variable — https://github.com/sun-typeface/SUIT (WOFF2); SIL Open Font License, see SUIT-LICENSE.txt.
- IBM Plex Mono Regular — https://github.com/google/fonts/tree/main/ofl/ibmplexmono (TTF); SIL Open Font License, see IBM-Plex-Mono-OFL.txt.

These assets are served locally via /assets/fonts/. The UI does not request remote fonts at runtime.

- KIMM Bold (한국기계연구원 서체) — https://www.kimm.re.kr/webfont ; KOGL Type 1, attribution is included in the collapsed font/method credits. Webfont source: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2212@1.0/KIMM_Bold.woff2 . Used for page h1 headings only, not the product wordmark.
